# 🚀 Installation

```bash
git clone https://github.com/akshxt0/Zenith.git

cd Zenith

python -m venv .venv

source .venv/bin/activate
# Windows
# .venv\Scripts\activate

pip install -r requirements.txt

uvicorn app.main:app --reload
```

Open:

```
http://127.0.0.1:8000
```
